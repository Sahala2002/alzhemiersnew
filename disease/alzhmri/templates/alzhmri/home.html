ABOUT THE SYSTEM

Brain MRI classification

This application is an academic machine learning project developed to classify brain MRI images using a trained deep learning model.

The system accepts an MRI image, performs the required preprocessing and passes the image to the trained classification model. The resulting class probabilities are then presented to the user.

Learn About the Project →
AI

ResNet50 Transfer Learning

The project uses a ResNet50-based transfer learning approach for brain MRI image classification.

Image Preprocessing

Uploaded images are converted to RGB, resized to 224 × 224 pixels and normalized before prediction.

Classification

The trained model generates probability values for the four categories represented in the dataset.
